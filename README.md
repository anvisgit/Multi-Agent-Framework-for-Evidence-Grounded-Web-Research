# Multi-Agent Framework for Evidence-Grounded Web Research

This repository tracks the research assistant across four incremental versions. Start with [v4](v4/README.md) for the current implementation; earlier versions remain available to show how the project evolved.

| Version | Main capability | What it adds over the previous version |
|---|---|---|
| [v1](v1/README.md) | CLI research workflow | Initial planner, researcher, critic, and writer roles with web search |
| [v2](v2/README.md) | Web app and follow-up research | Streamlit UI, Critic-led second search, and report memory |
| [v3](v3/README.md) | Retrieval-augmented workflow | Chunking, local embeddings, and ChromaDB passage retrieval |
| [v4](v4/README.md) | Verification and evaluation | Sentence-level evidence checks and a 15-question three-way benchmark harness |

Each version has its own setup and limitations in its README.
